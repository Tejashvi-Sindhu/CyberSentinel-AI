# Contributing

Thanks for taking an interest in CyberSentinel AI. This is an educational project and contributions should keep the limitations of security ML explicit.

## Development setup

1. Use Python 3.11 in a virtual environment.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Run tests with `python -m pytest`.
4. Run the dashboard with `python -m streamlit run app.py` after training demo models.

## Pull requests

- Explain the problem and the change.
- Add or update tests for behaviour changes.
- Do not include credentials, sensitive traffic captures, datasets, or generated model files.
- Do not present synthetic demo metrics as evidence of real-world detection quality.
- Keep changes focused and document limitations.
