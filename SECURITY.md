# Security policy

## Scope

CyberSentinel AI is an educational tool for analysing user-supplied CSV network-flow records. It is not a production IDS and does not capture live traffic.

## Reporting a concern

Please do not publish sensitive traffic samples, credentials, or personal data in an issue. For a security concern in this student project, contact the repository owner privately through their GitHub profile: https://github.com/Tejashvi-Sindhu

## Safe use

- Analyse only data you are authorised to use.
- Treat predictions as triage signals, not confirmed incidents.
- Only load model artifacts you trust.
- Never commit secrets, sensitive captures, or private datasets.
