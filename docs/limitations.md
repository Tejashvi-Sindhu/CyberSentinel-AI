# Limitations and responsible use

- Synthetic demo data is for workflow testing only and cannot establish real-world accuracy.
- A flagged anomaly is not necessarily malicious; an unflagged record is not guaranteed safe.
- Model quality depends on feature compatibility, representative data, labels, and evaluation design.
- Risk scores are prioritisation aids, not calibrated probabilities of compromise.
- This project analyses supplied CSVs; it does not capture packets or monitor a live network.
- Only analyse data you are authorised to use, and never commit sensitive captures or credentials.
