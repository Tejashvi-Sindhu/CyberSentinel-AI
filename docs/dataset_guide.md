# Dataset guide

The training pipeline is intended for labelled network-flow CSVs such as data derived from CIC-IDS2017. Before use:

1. Obtain the dataset from its official source and review its licence/terms.
2. Preserve source attribution in reports and presentations.
3. Remove identifiers and sensitive information where appropriate.
4. Confirm the CSV contains the exact features expected by the selected model.
5. Use a reproducible train/test split and report precision, recall, F1-score, class balance, and false-positive rate.
6. Keep the dataset outside Git unless redistribution is explicitly permitted.

Synthetic demo data is not a substitute for evaluation on representative traffic.
